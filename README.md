# TrafficGuardAI 🚗

AI-powered traffic monitoring and vehicle detection system built using Python, YOLO, OpenCV, and Streamlit.

## 🚀 Features

- 🚗 Vehicle detection
- 🔢 Unique vehicle counting
- 📊 Traffic statistics
- 🚦 Traffic congestion detection
- 🎥 Video-based traffic analysis
- 📍 Vehicle tracking
- 🖥️ Interactive Streamlit dashboard

## 🛠️ Technologies Used

- Python
- YOLO
- OpenCV
- Streamlit
- NumPy
- Pandas
- Computer Vision
- Deep Learning

## 📂 Project Files

- `app.py` – Streamlit application
- `detection.py` – Vehicle detection
- `congestion_detection.py` – Traffic congestion detection
- `traffic_statistics.py` – Traffic statistics
- `unique_vehicle_count.py` – Unique vehicle counting
- `vehicle_tracking.py` – Vehicle tracking
- `video_detection.py` – Video vehicle detection
